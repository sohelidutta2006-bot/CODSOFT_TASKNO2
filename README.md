# 🌿 FitLife – Responsive Landing Page

A modern, clean, and responsive fitness landing page built using **HTML5 and CSS3**. This project demonstrates responsive web design, CSS Flexbox, CSS Grid, and modern styling techniques.

## 📌 Features

* 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices.
* 🧭 **Navigation Bar** – Simple navigation with links to different sections.
* 🏋️ **Hero Section** – Attractive headline, description, and call-to-action buttons.
* ✨ **Features Section** – Highlights the main benefits using feature cards.
* 👋 **About Section** – Introduces the FitLife brand.
* 🚀 **Call-to-Action Banner** – Encourages visitors to get started.
* 📩 **Footer Section** – Includes quick links, contact information, and social links.
* 🎨 **Modern UI** – Uses CSS variables, rounded corners, shadows, and hover effects.
* 📐 **Responsive Layouts** – Built using CSS Flexbox, CSS Grid, and media queries.

## 🛠️ Technologies Used

* **HTML5** – Page structure and semantic elements.
* **CSS3** – Styling, layouts, animations, and responsiveness.
* **Google Fonts** – Typography.

   ```bash

   ```


3. Open `index.html` in your browser.

   Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## 📱 Responsive Design

The landing page adapts to different screen sizes:

* **Desktop:** Multi-column layouts for the hero, features, and footer.
* **Tablet:** Adjusted column layouts for better readability.
* **Mobile:** Vertically stacked sections and a wrapping navigation menu.
